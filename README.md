\# CSC4792 Group 43 – Gwembe Town Council Dataset



## Project Overview



This project focuses on collecting and preparing publicly available data from Gwembe Town Council.



## Dataset



The dataset contains structured information collected from the CDF report of 2025 relevant to Gwembe Town Council.



## Data Collection



Data was collected from publicly available council web resources using Python-based data extraction techniques.



## Data Processing



The data processing workflow included:



1. Data extraction

2. Data cleaning

3. Duplicate removal

4. Missing-value handling

5. Data standardisation

6. Dataset validation



## Files



\- `uncleaned_files/` – raw extracted data

\- `cleaned_files/` – cleaned final dataset

- Jupyter Notebook
- Data description Paper
